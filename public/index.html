World Cup Sweepstake

An HTTP/JSON API. There is no web UI; use the endpoints below.

Endpoints

  • GET/POST /participants, DELETE /participants/{id}
  • GET/POST /nations, DELETE /nations/{id}
  • GET/POST /assignments
  • GET/POST/PUT /matches
  • GET /league-table
  • POST /champion, GET /prizes/tournament-winner
  • POST /league/finalize, GET /prizes/league
